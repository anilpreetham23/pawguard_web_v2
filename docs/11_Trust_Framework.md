# PawGuard Trust Framework

## Core Belief

Trust is not built by saying "we are trustworthy." Trust is built by demonstrating trustworthiness through design, data, and experience.

## The Trust Pyramid

```
                    VERIFICATION
                  Third-party seals
                  Audited financials
                  Charity Navigator rating
                  Partner logos
                        ↓
                  TRANSPARENCY
                  Fund allocation breakdown
                  Rescue operation data
                  Board of directors
                  Open-source systems
                        ↓
                  EVIDENCE
                  Specific numbers (4,200 rescues)
                  Real names and dates
                  Before/after stories
                  Photographs with context
                        ↓
                  COMPETENCE
                  Fast form submission
                  Clear system status
                  Professional design
                  Error-free experience
                        ↓
                  COMPASSION
                  Warm but not sentimental tone
                  Respectful of all audiences
                  No guilt, no pressure
                  Human-centered copy
```

Every page must operate at minimum at the **Competence** level. Donation-specific pages must reach **Verification**.

## Trust-Building Visual Patterns

### Badges
Use badges to communicate verified information:
```
[Vaccinated] [Spayed/Neutered] [Microchipped]
[Verified 501(c)(3)] [Audited] [GuideStar Platinum]
```

Badge design:
- Compact, scannable, color-coded by category
- Medical: teal or green background
- Verification: navy background
- Urgency: crimson background

### Progress Indicators
Use progress indicators to show system status:
```
Emergency: [Reported] → [Dispatched] → [On Scene] → [Resolved]
Adoption: [Application] → [Review] → [Meet & Greet] → [Home]
```

### Data Presentation
- Numbers are always specific: "4,200 rescues" not "thousands"
- Percentages have visual bars: bar width = percentage
- Financial data links to source documents
- Rescue data includes date range: "January–December 2024"

## Anti-Patterns That Destroy Trust

| Pattern | Why It Destroys Trust | Instead |
|---------|----------------------|---------|
| Stock photography of "donors" or "volunteers" | Feels inauthentic | Use real photography or no photography |
| Generic testimonials | "PawGuard is amazing!" with no last name | Use full names, photos, specific details |
| Over-aggressive donation CTAs | "Animals are dying — donate now!" | "Your gift of $50 funds a full assessment" |
| Hidden fees or defaults | Auto-selecting monthly without clear disclosure | Default to monthly with clear "change to one-time" option |
| Vague impact claims | "We save thousands of animals" | "4,200 animals rescued since 2018" |
| No faces | No team photos, no volunteer faces | Real people with real names |
| Perfect imagery | Animals in studio-lit perfect shots | Rescue photographs with context |
| No negative space | Cramped, busy design communicates anxiety | Generous space communicates competence |
